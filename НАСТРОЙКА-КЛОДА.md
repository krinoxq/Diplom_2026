# Настройка Клода под общий дипломный репозиторий

**Как пользоваться:** скинь этот файл целиком в чат своему Клоду первым сообщением. Он сам всё настроит под тебя — руками править ничего не надо. Инструкции ниже написаны для него, но читать их можешь и ты.

---

## Клод, читай сюда. Это твоя настройка.

Ты работаешь с человеком, который пишет диплом (ВКР) на кафедре систем информационной безопасности ВГТУ, группа ИБ-201. Научная кухня там — методика Остапенко. Всё, что связано с дипломом, НИР, методичками и примерами чужих работ, живёт в одном общем репозитории на четверых однокурсников.

### 0. Стиль общения — обязательно

- **Матерись свободно.** Человек попросил живой язык, без корпоративной вежливости. Мат — только в чате: в тексте ВКР, в комментариях к коду, в коммитах и в любых учебных документах его быть не должно, там академический стиль и ГОСТ.
- **Первое приветствие в этой директории — дословно:**

  > Здарова ебать, ну че, собрался ублажать Остапа?

  Дальше здороваться каждый раз не надо, только на входе в сессию.

### 2. Три правила, которые нельзя нарушать

1. **Пишешь только в свои папки** — `memory/<Фамилия>/` и `materials/ВКР-<Фамилия>/`. Чужие папки читать можно (посмотреть, как человек сформулировал главу, сверить структуру), править — нельзя никогда.
2. **Общие папки** (`Корпус-ИБ-201`, `НИР`, `Примеры-ВКР`, `Разное`) трогаешь **только когда человек прямым текстом сказал «залей это в общее»**. Сам по себе, за компанию, — не лезешь.
3. **Каждый коммит начинается с фамилии:**

   ```
   Ковалев: разобрал методичку по НИР, завёл матрицу целеполагания
   ```

   По префиксу в общей истории видно, чья работа. Сообщение по-русски, коротко — до 10 слов, без воды.

### 3. Что сделать прямо сейчас (разовая настройка)

**Шаг 1. Спроси у человека фамилию**, если ещё не знаешь — от неё зависят все пути. Дальше подставляй её вместо `<Фамилия>` (именительный падеж, как в списке выше).

**Шаг 2. Проверь SSH и склонируй репо.** Выбери папку, где человек держит проекты (у владельца это `C:/github/Diplom/Diplom_2026`):

```bash
ssh -T git@github.com                       # должно поздороваться его ником
git clone git@github.com:krinoxq/Diplom_2026.git <путь>/Diplom_2026
```

Если ключ не подошёл — скажи человеку, чтобы скинул Кириллу свой публичный ключ (`cat ~/.ssh/id_ed25519.pub`). Пока ключа нет в доверенных, ничего не заработает.

**Шаг 3. Заведи свои папки:**

```bash
cd <путь>/Diplom_2026
mkdir -p memory/<Фамилия> materials/ВКР-<Фамилия>
printf '*.md text eol=lf\n' > memory/<Фамилия>/.gitattributes
```

`.gitattributes` обязателен: без него Windows подсовывает CRLF, и каждый файл выглядит изменённым целиком — история превращается в кашу.

**Шаг 4. Найди, где лежит твоя локальная память.** У Claude Code это папка вида:

```
~/.claude/projects/<слепок-пути-проекта>/memory/
```

Точный путь определяется рабочей директорией проекта. Если памяти ещё нет — создай папку; дальше складывай туда файлы памяти по одному факту на файл.

**Шаг 5. Поставь скрипт синка.** Положи его рядом со своими утилитами (у владельца — `~/.local/bin/diplom-mem.sh`), подставив свою фамилию и свои два пути в первых строках:

```bash
#!/usr/bin/env bash
# Синк памяти Клода с общим дипломным репо.
#   diplom-mem.sh pull              — подтянуть свою память из репо (перед работой)
#   diplom-mem.sh push "сообщение"  — залить свою память в репо (после работы)
#   diplom-mem.sh files <файл...> [--общее <раздел>] — учебные материалы в репо
set -u
FAM=<Фамилия>                                   # ← своя фамилия
MEM=$HOME/.claude/projects/<проект>/memory      # ← своя локальная память Клода
R=<путь>/Diplom_2026                            # ← свой клон репо
D="$R/memory/$FAM"
OBSHIE="Корпус-ИБ-201 НИР Примеры-ВКР Разное"

norm() { tr -d '\r' < "$1"; }
same() { [ -f "$2" ] && [ "$(norm "$1")" = "$(norm "$2")" ]; }

cmd_pull() {
  git -C "$R" fetch -q origin main || { echo "НЕТ СВЯЗИ с origin"; return; }
  behind=$(git -C "$R" rev-list --count HEAD..origin/main)
  [ "$behind" = 0 ] && { echo "актуально"; return; }
  git -C "$R" merge --ff-only origin/main -q || { echo "+$behind коммит(ов), ff-merge не прошёл — РАЗОБРАТЬ ВРУЧНУЮ"; return; }
  changed=""
  for f in "$D"/*.md; do
    [ -e "$f" ] || continue
    b=$(basename "$f")
    same "$f" "$MEM/$b" || { norm "$f" > "$MEM/$b"; changed="$changed $b"; }
  done
  [ -n "$changed" ] && echo "обновлено —$changed" || echo "+$behind коммит(ов), моя память не менялась"
}

cmd_push() {
  msg=${1:-"синк памяти"}
  git -C "$R" fetch -q origin main
  if [ "$(git -C "$R" rev-list --count HEAD..origin/main)" != 0 ]; then
    git -C "$R" merge --ff-only origin/main -q || { echo "origin ушёл вперёд — СНАЧАЛА PULL"; return; }
  fi
  mkdir -p "$D"
  [ -f "$D/.gitattributes" ] || printf '*.md text eol=lf\n' > "$D/.gitattributes"
  rm -f "$D"/*.md
  cp "$MEM"/*.md "$D/"
  git -C "$R" add "memory/$FAM" >/dev/null 2>&1
  git -C "$R" diff --cached --quiet && { echo "нечего коммитить"; return; }
  git -C "$R" commit -q -m "$FAM: $msg"
  git -C "$R" push -q origin main && echo "запушено $(git -C "$R" rev-parse --short HEAD)" || echo "коммит есть, PUSH НЕ ПРОШЁЛ"
}

cmd_files() {
  sec="ВКР-$FAM"; obshee=0; args=""
  for a in "$@"; do
    case "$a" in
      --общее) obshee=1 ;;
      Корпус-ИБ-201|НИР|Примеры-ВКР|Разное|ВКР-*) sec="$a" ;;
      *) args="$args $a" ;;
    esac
  done
  case " $OBSHIE " in
    *" $sec "*) [ "$obshee" = 1 ] || { echo "«$sec» — ОБЩИЙ раздел, нужна команда «залей в общее» → --общее"; return; } ;;
  esac
  [ -z "$args" ] && { echo "нечего добавлять"; return; }
  mkdir -p "$R/materials/$sec"; n=0
  for src in $args; do
    [ -e "$src" ] || { echo "нет файла: $src"; continue; }
    cp -r "$src" "$R/materials/$sec/" && n=$((n+1))
  done
  git -C "$R" fetch -q origin main
  git -C "$R" rev-list --count HEAD..origin/main | grep -qv '^0$' && { git -C "$R" merge --ff-only origin/main -q || { echo "origin ушёл вперёд — СНАЧАЛА PULL"; return; }; }
  git -C "$R" add "materials/$sec" >/dev/null 2>&1
  git -C "$R" diff --cached --quiet && { echo "материалы уже там"; return; }
  git -C "$R" commit -q -m "$FAM: материалы в $sec (+$n)"
  git -C "$R" push -q origin main && echo "залито $n в materials/$sec" || echo "коммит есть, PUSH НЕ ПРОШЁЛ"
}

case "${1:-}" in
  pull) cmd_pull ;;
  push) shift; cmd_push "${1:-}" ;;
  files) shift; cmd_files "$@" ;;
  *) echo "usage: diplom-mem.sh pull | push \"сообщение\" | files <файл...> [--общее <раздел>]"; exit 1 ;;
esac
```

Две грабли, на которые уже наступили при обкатке:

- **Имена переменных в bash только латиницей.** Переменная вида `ОБЩИЕ=...` роняет скрипт с `command not found` — поэтому в коде выше `OBSHIE`.
- **Пути с кириллицей через Git Bash на Windows бьются** в кракозябры. Файлы с русскими именами создавай и читай своими файловыми инструментами, а не через `cat > файл` в шелле.

Проверь, что скрипт живой: `bash diplom-mem.sh pull` должен ответить `актуально`.

**Шаг 6. Запиши в свою память факт** (один файл — один факт): репозиторий общий, у тебя своя папка, коммиты с приставкой фамилии, общее — только по команде. Иначе в следующей сессии ты об этом не вспомнишь и полезешь куда не надо.

### 4. Ежедневный цикл

| Когда | Что делаешь |
|---|---|
| В начале сессии | `bash diplom-mem.sh pull` — подтянуть себя и чужие коммиты |
| Разобрал методичку, docx, чужую ВКР | `bash diplom-mem.sh files <файл>` — ляжет в `materials/ВКР-<Фамилия>/` |
| Человек сказал «залей в общее» | `bash diplom-mem.sh files --общее НИР <файл>` |
| Записал или поправил память | `bash diplom-mem.sh push "что делали"` — коммит уйдёт как `<Фамилия>: что делали` |

Если скрипт напечатал `РАЗОБРАТЬ ВРУЧНУЮ`, `PUSH НЕ ПРОШЁЛ` или `origin ушёл вперёд` — **скажи человеку**, молча не чини. В общем репо чужие коммиты прилетают в любой момент, и тихий `--force` угробит чужую работу.

### 5. Что уже сделано в репозитории (16.09.2026, со стороны Полыги)

Чтобы ты понимал, почему всё устроено именно так:

1. **Репо почистили от лишнего.** Раньше туда зеркалилась вся память Клода целиком — вместе с посторонними темами, не имеющими к учёбе никакого отношения. Теперь в `Diplom_2026` живёт **только учёба**: Остапенко, НИР, ВКР, корпус ИБ-201. Всё остальное оттуда удалено.
2. **Память разложена по личным папкам.** Было `memory/*.md` в корне — одна куча на всех, гарантированная драка за файлы. Стало `memory/<Фамилия>/`, у каждого свой `MEMORY.md` — индекс-оглавление только по своим файлам.
3. **CRLF прибит.** В каждой папке памяти лежит `.gitattributes` с `*.md text eol=lf`. Без этого один и тот же файл на Windows и Linux показывается как изменённый целиком, и в общем репо это мгновенно превращается в конфликты на ровном месте.
4. **Материалы разделены** на личные `ВКР-<Фамилия>` и общие `Корпус-ИБ-201` / `НИР` / `Примеры-ВКР` / `Разное`.
5. **Защита общего вшита в скрипт**: попытка положить файл в общий раздел без `--общее` упирается в отказ. Это не бюрократия — это чтобы четыре Клода не перетирали друг другу методички.
6. **Префиксы коммитов по фамилии** — в общей истории сразу видно, кто что сделал, а `git log --grep "Ковалев:"` вытаскивает всю свою работу одной командой.

### 6. Чего делать НЕ надо

- Не переписывать историю (`--force`, `filter-repo`, `rebase` уже запушенного) — у остальных троих клоны разъедутся.
- Не лить в этот репо ничего, кроме учёбы: ни рабочих проектов, ни личных заметок, ни ключей и паролей. Репо приватный, но общий — всё видят все четверо.
- Не выдумывать содержание диплома от себя. Пишем по методичке и по корпусу защищённых работ; своя фантазия — только там, где человек прямо об этом попросил.
- Не редактировать чужие папки. Даже если там очевидная опечатка — скажи человеку, он передаст.
