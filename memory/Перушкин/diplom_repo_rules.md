Репо `git@github.com:krinoxq/Diplom_2026.git` (main, приватный), клон в `C:\github\Diplom\Diplom_2026`. Владелец — Кирилл Полыга; участники Полыга, Ковалев, Перушкин, Ширинкин. Пользователь — **Перушкин** (GitHub `perushkinnekk-web`), ВКР на кафедре СИБ ВГТУ, группа ИБ-201, методика Остапенко.

- Писать только в `memory/Перушкин/` и `materials/ВКР-Перушкин/`. Чужие папки — только читать.
- Общие `Корпус-ИБ-201`, `НИР`, `Примеры-ВКР`, `Разное` — только по прямой команде «залей в общее».
- Коммит: `Перушкин: <до 10 слов по-русски>`.
- Никакого `--force`/rebase запушенного; `РАЗОБРАТЬ ВРУЧНУЮ` / `PUSH НЕ ПРОШЁЛ` / `origin ушёл вперёд` — сказать человеку, не чинить молча.
- В репо только учёба: без рабочих проектов, личного, ключей.
- Содержание диплома не выдумывать — по методичке и корпусу защищённых работ.

**Why:** репо общий на четверых, чужие коммиты прилетают в любой момент; инструкция `НАСТРОЙКА-КЛОДА.md` в корне репо.
**How to apply:** синк — `bash ~/.local/bin/diplom-mem.sh pull` в начале сессии, `files <файл>` для материалов, `push "что делали"` после правки памяти. См. [[chat-style]].

Сессию по диплому запускать **из `C:\github\Diplom\Diplom_2026`**: скрипт синка читает память по пути `~/.claude/projects/C--github-Diplom-Diplom-2026/memory`, и запуск из другой директории (например с рабочего стола) уводит записанную память в чужую папку, откуда она в репо не попадёт. Репо лежит не в домашней папке — искать `.git` по `C:\Users\Nikita` бесполезно. См. [[ostap-new-vkr-structure]], [[perushkin-vkr-state]].
