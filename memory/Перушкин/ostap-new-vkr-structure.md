17.09.2026 Остапенко («Остап») выдал новую типовую структуру ВКР — файл `materials/Обновление от Остапа 17.09.2026.docx`:

1. Исследование аналогов и постановка задач работы.
2. Создание информационного обеспечения, необходимого и достаточного для проактивного риск-анализа объекта исследования.
3. Создание аналитического обеспечения проактивной оценки рисков нарушения ИБ объекта исследования.
4. Создание аналитического обеспечения проактивного регулирования рисков нарушения ИБ объекта исследования.
5. Автоматизация предложенных методик и обоснование эффективности мер информационной защиты объекта исследования.

**Why:** это ломает все матрицы целеполагания и содержания, свёрстанные до 17.09.2026 — писать главы по старому плану значит писать в стол.

**How to apply:**
- Матрица целеполагания теперь на **4 противоречия/задачи** (главы 2–5). У первой главы противоречия и задачи нет — глав больше, чем задач, это норма по новой схеме.
- Шаблон матрицы — `materials/Рекомендуемая (Для основной массы ВКР) структура целеполагания в сфере обеспечения ИБ 17.09.26.xlsx`, заполненный образец — `materials/матрица_целеполагания_+содержание Мальцевой Дарьи (По новой структуре Остапа 17.09.26) 21.09.26.docx`.
- 21.09.2026 Белоножкин прислал теоретическую базу (`materials/проактивный риск-анализ (От Белоножкина 21.09.2026).docx`): STRIDE / PASTA / деревья атак, FAIR, ALE, ROSI, метод Монте-Карло, ASM, CTI. Ядро — замкнутый цикл «идентификация сценария → первичный риск → выбор мер → остаточный риск → количественная верификация (ROSI, ΔALE)». Этот цикл должен просматриваться в главах 3–5.
