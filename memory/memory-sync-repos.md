Когда сохраняю память по теме **DevOps** — после записи в `~/.claude/projects/C--Users-iasti--local-bin/memory/` дополнительно зеркалю всю папку памяти в `C:/github/DevOps-Learning/memory/` и пушу. Когда тема **диплом / НИР / учёба** — то же самое в `C:/github/Diplom/Diplom_2026/memory/` (сам `C:/github/Diplom` — не репозиторий, это просто папка-обёртка; репо лежит внутри).

Оба репо приватные, ветка `main`, remote по SSH (`git@github.com:krinoxq/DevOps-Learning.git`, `git@github.com:krinoxq/Diplom_2026.git`), ключ рабочий.

**Why:** нужна общая память между несколькими устройствами — на другом ПК Claude поднимает её из репозитория, а не начинает с нуля.

**How to apply:**
- Зеркалить папку памяти **целиком** (не только тематический файл) — так решил пользователь.
- Перед пушем `git fetch` и сверить с `origin/main`: если удалёнка ушла вперёд — сначала подтянуть и слить чужие изменения памяти, только потом писать свои.
- `git add` только `memory/` — в DevOps-Learning регулярно висят чужие незакоммиченные правки (`LOG.md`, `ROADMAP.md` и прочее), их не трогать.
- Коммит: кратко что делали, **не больше 10 слов**, по-русски (стиль репо: «залил память с основного пк»).
- В начале разговора по этим темам — `git pull` в соответствующем репо и сверка с локальной памятью.
