Матрица целеполагания — **не таблица при дипломе, а его скелет**: каждая строка разворачивается в главу, поэтому выдуманная строка = глава, которую потом не написать. Так это сформулировал староста группы КБ (его собственная тема совпадает с темой Егорова прошлого года, он расширяет её, находя противоречия в чужой работе). То же самое записано и в `ВАЖНО НИРС CLAUDE.txt`: аналоги и противоречия пишутся ПОСЛЕДНИМИ, когда уже видно, чего средствам не хватает.

**Актуальная версия (на 25.10.2026)** — `Diplom_2026/materials/Матрица целеполагания - 4 темы ПРЕДВАРИТЕЛЬНАЯ!!! (по разбору Остапа 27.09.26).xlsx` плюс её `ДЛЯ ПЕЧАТИ` (.xlsx/.pdf), коммит 01.10; старые версии убраны в `materials/old/` — см. [[materials-old-folder]]. Исходно на рабочем столе (OneDrive) лежал `Матрица целеполагания - 4 темы.xlsx` — листы «Как читать», по листу на каждого и «ML — как делать». Пользователь сам держит копии версий с суффиксом ` v1`. Образец формата — `Матрица целеполагания.xlsx`, чужая работа по brute-force с битыми ячейками (в D3 результат продублирован, в E2 мусорное «якоррупцию»).

Колонки: № | Противоречия между | Задачи | Результаты | Новизна | Практическая ценность | Теоретическая ценность. Правило арифметики действует **внутри** одной работы, между работами числа совпадать не обязаны: Полыга 5, Ширинкин 6, Ковалев 5, Перушкин 5.

Структуры намеренно разные, чтобы четыре работы не читались как один шаблон:
- **Полыга** — модель кластера и дерево угроз → база → метрика → типовые сценарии → система и меры
- **Ширинкин** — база по этапам → секреты конвейера → целостность артефакта → метрика → распространение компрометации → регламенты
- **Ковалев** — модель СУД → **вероятность** через стойкость аутентификации (NIST SP 800-63, уровни AAL) → **ущерб** → сценарии → регулирование. Мера риска расщеплена по строкам: строка 2 даёт вероятность, строка 3 — ущерб; такого деления нет больше ни у кого
- **Перушкин** — база → метрика → дерево угроз и сценарии → риск-ландшафт отдельной строкой (правка руководителя из `НИР\certificate.txt`) → регламенты

Разведены также заголовками колонок, порядком «новизна / практическая / теоретическая», оборотами («впервые…» / «научная новизна состоит в том, что…» / «отличительной особенностью… является…» / «в отличие от известных решений…») и профильным источником у каждого. Проверено машинно: общих дословных фрагментов длиной 8 слов между работами — ноль. Общими остаются только CVSS и EPSS в строке про метрику.

**Не доказано на 12 сентября 2026 г.:** анализ аналогов проведён только у Перушкина (OpenSCAP, Lynis, CIS-CAT, ScanOVAL, Wazuh — четыре подтверждённых пробела = четыре противоречия). У Полыги, Ширинкина и Ковалева противоречия выведены по аналогии и держатся на допущении. Уязвимые места новизны: у Полыги attack path analysis уже есть в Kubescape и CNAPP, у Ковалева BloodHound строит граф достижимости по правам, у Ширинкина SLSA уже даёт provenance — эти три формулировки придётся сужать по факту.

**Why:** матрица переписывалась несколько раз, и решения (почему у кого столько строк, почему у Ковалева расщеплена мера риска) из самого файла не восстанавливаются.

**How to apply:** строку добавлять или убирать только целиком, по всем колонкам. Прежде чем править формулировки — проверять по [[ostapenko-method]], а новизну сверять с тем, что аналоги уже умеют; если аналог это делает, формулировку сужать, а не защищать.
