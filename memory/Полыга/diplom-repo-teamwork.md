С 16.09.2026 `github.com/krinoxq/Diplom_2026` — **общий** репозиторий, в котором диплом делают четверо однокурсников ИБ-201: **Полыга** (это я, Кирилл — мой пользователь), **Ковалев**, **Перушкин**, **Ширинкин**. У каждого свой Claude, все ходят в один и тот же репо. Их SSH-ключи добавлены в доверенные, каждый коммитит от своего имени.

Структура:

- `memory/<Фамилия>/` — личная память каждого. Моя — `memory/Полыга/`.
- `materials/ВКР-<Фамилия>/` — личные материалы (черновики, главы, правки руководителя).
- `materials/Корпус-ИБ-201`, `materials/НИР`, `materials/Примеры-ВКР`, `materials/Разное` — **общие**.

**Why:** четыре Клода в одном репо иначе передерутся за файлы и перезапишут чужое. Разделение по папкам даёт общий доступ к корпусу и методичкам без риска влезть в чужую работу.

**How to apply:**
- Пишу **только в свои** `memory/Полыга/` и `materials/ВКР-Полыга/`. Чужие папки — читать можно, править нельзя.
- **Общее трогаю только по прямой команде «залей это в общее»** — иначе руки прочь. В скрипте это защищено флагом `--общее`.
- Каждое сообщение коммита начинается с `Полыга: ` — по префиксу видно, чья работа. У остальных так же, со своей фамилией.
- Перед работой — `pull`, после — `push`, чтобы не ловить расхождения с чужими коммитами: [[memory-sync-repos]].
- Про DevOps и личное в этот репо не льём вообще — там только учёба.

Раздатка для однокурсников — `НАСТРОЙКА-КЛОДА.md` в корне репо: файл кидают в чат своему Клоду, тот сам ставит себе скрипт `diplom-mem.sh`, заводит папки и правила. Там же прописан их стиль: мат в чате и приветствие «Здарова ебать, ну че, собрался ублажать Остапа?». Файл общий — коммитится только по команде «залей в общее».
