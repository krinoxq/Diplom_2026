Когда надо выбрать «актуальную» версию работы (НИРС, матрица, глава), берётся файл с самой поздней датой: по дате в имени и по дате коммита в Diplom_2026. Слова «Финал», «итог», «АКТУАЛ», «финальный» в имени файла ничего не значат.

**Why:** 04.10.2026 при сборке папки для Чопорова я взял `Полыга К.Ю. НИР — Финал 17.09.26`, а свежее был `Полыга К.Ю. ВКР 23.09.26`, и пользователь поправил: «бери самые последние даты всегда».

**How to apply:** перед копированием или отправкой сравнивать `git log -1 --format=%ci` и даты в именах всех кандидатов одного автора; брать самый новый. Связано с [[diplom-repo-teamwork]].
