Пользователь с тремя одногруппниками пишет НИР (отчёт по производственной практике) с условием, что он затем без переписывания станет **первой главой ВКР**. Руководитель — Чопоров О. Н., кафедра систем информационной безопасности ВГТУ.

Темы:
- **Полыга** (вероятно сам пользователь — Кирилл Полыханов по email) — оценка и регулирование киберрисков инфраструктуры контейнеризации Kubernetes при компрометации контейнерных приложений
- **Ширинкин** — киберриски корпоративной DevOps-инфраструктуры при нарушении безопасности CI/CD-процессов
- **Ковалев** — регулирование рисков корпоративной системы управления доступом при компрометации учётных записей
- **Перушкин** — киберриски серверной инфраструктуры Linux при эксплуатации ошибок конфигурирования сервисов

Все четыре темы — «Разработка интеллектуальной системы оценки/регулирования…». Полный разбор с каркасом, заготовками формулировок и чек-листом лежит на рабочем столе в файле `ВАЖНО НИРС CLAUDE.txt`; онлайн-версия разбора темы Перушкина — https://claude.ai/code/artifact/4a7f4d07-a573-4c58-a226-483a0824eb21

Целеполагание разложено в [[goal-matrix-4-themes]], подход к машинному обучению — в [[ml-approach-diplomas]].

[[ib201-diploma-corpus]]), `НИР/` (работы Косухина), `Разное/` (`ВАЖНО НИРС CLAUDE.txt`, `Каркас НИР Linux.pdf`, `Матрица целеполагания.xlsx`, `Книга1.xlsx` со списком тем четверых и примерами тем корпуса, `Наработки общие по НИРС.docx`, рекомендации по оформлению, планы в jpg). Оригиналы остались на рабочем столе, репо — зеркало для второго устройства.

**Why:** работа идёт не одну сессию, а контекст (кто какую тему пишет, под кого пишем) заново не выводится.

**How to apply:** перед советами по НИР сверяться с [[ostapenko-method]] и [[ib201-diploma-corpus]]; главный риск проекта — совпадение текста в общих разделах у четверых, поэтому у каждого свой профильный фреймворк (ATT&CK for Containers / OWASP CI-CD / NIST 800-63 / CIS Benchmarks).
