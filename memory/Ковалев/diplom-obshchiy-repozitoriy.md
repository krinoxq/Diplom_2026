# Общий дипломный репозиторий ИБ-201

Диплом Ковалева живёт не только локально: есть общий приватный репозиторий на
четверых однокурсников — `git@github.com:krinoxq/Diplom_2026.git`, ветка `main`.
Владелец — Кирилл Полыга, участники: Полыга, Ковалев, Перушкин, Ширинкин.
Правила настройки Ковалев передал файлом «НАСТРОЙКА-КЛОДА.md» (16.09.2026).

Главная мысль, из которой следует всё остальное: репозиторий **общий, и в нём
одновременно работают четыре Клода**. Поэтому любое действие, затрагивающее
чужое, запрещено по умолчанию.

## Три правила, которые нельзя нарушать

1. **Писать только в свои папки** — `memory/Ковалев/` и
   `materials/ВКР-Ковалев/`. Чужие папки (`ВКР-Полыга`, `ВКР-Перушкин`,
   `ВКР-Ширинкин`) читать можно — посмотреть формулировку главы, сверить
   структуру, — но править нельзя никогда, даже очевидную опечатку. Об опечатке
   надо сказать Ковалеву, он передаст.
2. **Ничего не отправлять в общий репозиторий без прямой команды Ковалева.**
   Исходная инструкция Полыги требовала команды «залей это в общее» только для
   общих разделов (`Корпус-ИБ-201`, `НИР`, `Примеры-ВКР`, `Разное`), а синк
   памяти описывала как рутину в конце сессии. Ковалев это правило расширил
   (16.09.2026): команда нужна на **любую** отправку — включая `push` собственной
   памяти и заливку материалов в свою же папку `ВКР-Ковалев`. Причина в том, что
   в памяти живут не только учебные факты, но и личные заметки (например, как
   ему объяснять новое и в каком стиле разговаривать), а репозиторий читают трое
   однокурсников. Поэтому `diplom-mem.sh push` и `files` запускать только по
   явной просьбе; `pull` в начале сессии безопасен и командой не требуется.
3. **Каждый коммит начинается с фамилии**: `Ковалев: разобрал методичку по НИР`.
   По префиксу в общей истории видно, чья работа, и `git log --grep "Ковалев:"`
   вытаскивает всю свою. Сообщение по-русски, до десяти слов, без воды.

## Локальные пути и цикл работы

Клон репозитория — `C:/github/Diplom_2026` (в Git Bash `/c/github/Diplom_2026`),
путь намеренно без кириллицы. Синк памяти делает скрипт
`C:/Users/koval/.local/bin/diplom-mem.sh`:

- `bash diplom-mem.sh pull` — в начале сессии, подтянуть свою память и чужие
  коммиты; единственная команда, которую можно запускать без спроса;
- `bash diplom-mem.sh push "что делали"` — залить свою память, **только по
  прямой команде Ковалева**;
- `bash diplom-mem.sh files <файл>` — учебный материал в `materials/ВКР-Ковалев/`,
  тоже только по прямой команде;
- `bash diplom-mem.sh files --общее НИР <файл>` — в общий раздел, по команде
  «залей в общее».

Если скрипт напечатал `РАЗОБРАТЬ ВРУЧНУЮ`, `PUSH НЕ ПРОШЁЛ` или
`origin ушёл вперёд` — надо сказать Ковалеву, а не чинить молча: тихий `--force`
угробит чужую работу. Историю не переписывать вообще (`--force`, `filter-repo`,
`rebase` уже запушенного) — у остальных троих клоны разъедутся.

В репозиторий идёт **только учёба**: Остапенко, НИР, ВКР, корпус ИБ-201. Ни
рабочих проектов, ни личных заметок, ни ключей и паролей — репозиторий
приватный, но все четверо видят всё.

## Грабли, на которые уже наступали

Имена переменных в bash только латиницей: `ОБЩИЕ=...` роняет скрипт с
`command not found`. Пути с кириллицей через Git Bash на Windows бьются в
кракозябры, поэтому файлы с русскими именами надо создавать и читать файловыми
инструментами, а не через `cat > файл` в шелле. В каждой папке памяти лежит
`.gitattributes` с `*.md text eol=lf` — без него Windows подсовывает CRLF и файл
выглядит изменённым целиком.
